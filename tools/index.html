Cavalier Tools · 작은 도구 모음 · 정리 · 창 배치 · 색 따기 · 예약 종료

자잘한 PC 일을
트레이 하나로 끝내세요

다운로드 폴더 자동 정리, 창을 칸에 딱 맞추기, 화면 색 따기, PC 상태 위젯, PC 예약 종료 · 타이머, 키보드 · 마우스 잠금을 프로그램 하나에 모았어요. 화면 오른쪽 아래 트레이에서 조용히 돌다가, 필요할 때 단축키 하나로 불러 써요.

무료로 내려받기
Windows 10 · 11 (64비트)

어떤 프로그램인가요?

작은 일 하나 하려고 프로그램을 여러 개 깔다 보면 트레이가 아이콘으로 가득 차죠. Cavalier Tools는 자주 쓰는 작은 도구 여섯 가지를 한 프로그램에 넣었어요. 처음 화면에서 도구마다 켜고 끌 수 있어서, 쓰지 않는 도구는 꺼 두면 돼요. 다운로드 폴더가 늘 어지러운 분, 모니터에 창을 여러 개 띄워 일하는 분, 디자인 · 웹 작업으로 색을 자주 따는 분께 좋아요.

광고 · 로그인 · 회원가입이 없고, 파일이나 화면을 인터넷으로 보내지 않아요. 다른 프로그램이 이미 쓰고 있는 단축키는 빼앗지 않고, 다음 후보 키로 바꾼 뒤 알려 줘요. 폴더 정리를 잘못했으면 '되돌리기' 한 번으로 휴지통에 간 파일까지 제자리로 돌려놔요.

이렇게 써요

  1. 압축을 풀고 CavalierTools.exe를 켜요. 처음 화면에 네 칸(폴더 정리 · 창 배치 · 컬러 피커 · PC 상태)이 보이고, 왼쪽 목록에 예약 종료 · 잠금이 있어요.
  2. 폴더 자동 정리에서 지켜볼 폴더(예: 다운로드)를 더해요. 사진 · 문서 · 설치 파일을 나누는 기본 규칙이 들어 있어서 바로 쓸 수 있어요.
  3. 창을 옮길 때 Shift를 누르고 끌면 칸이 보이고, 놓으면 그 칸에 딱 맞춰져요. 색은 Win+Shift+C를 누르고 화면 아무 곳이나 클릭하면 복사돼요.
  4. 창을 닫아도 트레이에서 계속 돌아요. 트레이 아이콘을 오른쪽 클릭하면 '30분 뒤 PC 끄기' · '키보드 · 마우스 잠그기'를 바로 고를 수 있어요.

할 수 있는 것

🗂️ 폴더 자동 정리폴더를 지켜보다가 새 파일이 생기면 규칙대로 옮기기 · 복사 · 이름 바꾸기 · 휴지통 · 압축 풀기를 해요. 확장자 · 이름 · 크기 · 종류 · 날짜로 규칙을 만들고, 실행 전에 미리 보기로 확인할 수 있어요. 새 파일은 약 1.2초 만에 정리돼요.
↩️ 되돌리기정리한 기록이 남고, 실수했으면 '마지막 것 되돌리기'로 원래 자리로 돌려놔요. 휴지통으로 보낸 파일도 휴지통에서 꺼내 제자리에 돌려놔요.
🪟 창 배치 (칸에 딱 맞추기)반반 · 2:1 · 4칸 · 세 줄 · 가운데 넓게 등 기본 배치 9가지와, 격자 · 자유 모양으로 직접 만든 내 배치를 써요. Shift를 누르고 창을 끌면 칸이 보이고, Ctrl을 같이 누르면 여러 칸에 걸쳐요. 모니터 · 가상 데스크톱마다 배치를 따로 기억해요.
⌨️ 단축키로 창 옮기기 · 항상 위Win+Alt+방향키로 옆 칸으로 옮기고(약 0.004초, 윈도우 스냅과 거의 같은 빠르기), Win+Ctrl+T로 지금 창을 다른 창보다 늘 위에 고정해요. 고정한 창은 테두리 색으로 알려 줘요.
🎨 컬러 피커단축키를 누르고 화면 아무 곳이나 클릭하면 색이 복사돼요. 돋보기는 마우스 휠로 크게 볼 수 있고, 크게 하면 화면을 멈춰 한 점을 정확히 골라요. HEX · RGB · HSL · CMYK 등 18가지 형식과 직접 만든 형식으로 복사하고, 최근 색 20개를 기억해요. 시험한 64가지 색이 모두 정확했어요.
📊 PC 상태 위젯화면 구석에 CPU · 그래픽카드 · 메모리 · 디스크 · 온도 · 네트워크를 작은 그래프와 함께 보여 줘요. 투명도 · 위치 · 크기를 고르고, 게임이나 영상 볼 때는 마우스가 위젯을 지나가게 할 수 있어요. 너무 뜨겁거나 메모리 · 디스크가 모자라면 알려 줘요.
⏻ PC 예약 종료 · 알람'1시간 뒤' 또는 '오후 11시(매일)'에 PC 끄기 · 다시 시작 · 절전 · 최대 절전 · 로그아웃 · 화면 잠금 · 알람을 걸어요. 끄기 60초 전에 알려 주고, 그동안 취소 · 10분 미루기를 고를 수 있어요. 저장하지 않은 문서가 있으면 윈도우가 먼저 물어봐요(강제로 끄지 않아요).
⏱️ 집중 타이머집중 25분 → 쉬기 5분, 네 번마다 15분 길게 쉬기를 되풀이해요. 시간은 바꿀 수 있고, 단계가 끝나면 소리와 알림으로 알려 줘요.
🔒 키보드 · 마우스 잠금아이가 키보드를 두드리거나 키보드 · 화면을 닦을 때 잠가 두면, 눌러도 아무 일이 일어나지 않아요. 정한 키 조합(기본 Ctrl+Alt+U)이나 암호로 풀고, 'N분 뒤 저절로 풀기'도 고를 수 있어요. 잠긴 동안 화면은 어둡게 · 검게(청소용) · 그대로(영상 보기용) 중에 골라요.

이메일로 문의하기
  1. zip 파일을 받아요.
  2. 압축을 풀고 CavalierTools.exe를 실행해요. 설치 과정은 없어요.
  3. "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 눌러요.

자주 묻는 질문

키보드 · 마우스를 잠갔는데 푸는 방법을 잊었어요.

Ctrl+Alt+Del은 윈도우가 어떤 프로그램도 막지 못하게 해 두어서 잠긴 동안에도 돼요. Ctrl+Alt+Del → 작업 관리자에서 Cavalier Tools를 끄면 바로 풀려요. 잠글 때 'N분 뒤 저절로 풀기'를 켜 두면 더 안심이에요.

예약해 둔 시간에 PC가 꺼져 있었으면요?

한 번만 하는 예약은 PC를 다시 켰을 때 실행하지 않고 지운 뒤 알려 줘요. 켜자마자 꺼지는 일은 없어요. '매일' 예약은 다음 날 같은 시각으로 넘어가요.

단축키가 다른 프로그램과 겹쳐요.

다른 프로그램이 먼저 쓰고 있는 키는 빼앗지 않아요. 기본 키가 겹치면 다음 후보 키(예: Win+Shift+C → Win+Alt+C)로 바꾸고 알림으로 알려 줘요. [설정 → 켜진 단축키 한눈에]에서 모두 확인하고, 각 도구 화면에서 원하는 키로 바꿀 수 있어요.

작업 관리자처럼 관리자 권한으로 켠 창은 안 움직여요.

윈도우 보안 때문에 보통 프로그램은 관리자 권한 창을 옮기거나 고정할 수 없어요. [설정]에서 '관리자 권한으로 다시 켜기'를 누르면 그런 창도 옮길 수 있어요.

CPU 온도가 실제보다 낮게 나와요.

관리자 권한 없이 읽을 수 있는 메인보드 센서 값이라 그래요. LibreHardwareMonitor가 켜져 있으면 그 값을 가져와서 정확하게 보여 줘요.

설치는 어떻게 하나요?

zip 파일을 받아 원하는 곳에 압축을 풀고 exe 를 실행하면 끝이에요. 지우고 싶으면 폴더를 지우면 돼요. 여러 프로그램을 한 번에 설치 · 업데이트하려면 Cavalier 설치 도우미를 쓰세요.

7일이 지나면 어떻게 되나요?

무료판으로 계속 쓸 수 있어요. 자주 쓰는 기능은 그대로 무료이고, 큰 작업만 잠깐 기다리거나 정식판에서만 돼요.

"Windows의 PC 보호" 창이 떠요.

새로 나온 프로그램이라 나오는 안내예요. [추가 정보] → [실행]을 눌러 주세요.

인터넷에 제 정보를 보내나요?

아니요. 켤 때 홈페이지에서 '사용 중지된 키 목록'만 받아 오고, 이때도 내 정보는 보내지 않아요.
