Cavalier Backup · 폴더 백업 · 동기화

소중한 폴더를
잃어버리지 않게 백업하세요

문서 · 사진 폴더를 외장 하드, USB, 네트워크 폴더에 백업해요. 무엇이 복사되고 지워지는지 먼저 보여 주고, 덮어쓰거나 지운 파일은 예전 버전으로 남겨 둬요.

무료로 내려받기
Windows 10 · 11 (64비트)

어떤 프로그램인가요?

백업을 해 두었는데 막상 필요할 때 엉뚱한 파일로 덮여 있거나, 원본을 지우자 백업까지 지워져 버린 적이 있다면 이 프로그램이 맞아요. 실행하기 전에 새 파일 · 바뀐 파일 · 지워질 파일을 개수와 크기로 보여 주고, 덮어쓰거나 지우는 파일은 날짜별 '예전 버전 보관함'에 옮겨 둬서 언제든 되살릴 수 있어요.

USB가 빠져서 원본이 비어 보일 때, 한꺼번에 많은 파일이 지워지려 할 때, 원본과 대상을 거꾸로 고른 것 같을 때는 실행하지 않고 먼저 물어봐요. 복사 도중 컴퓨터가 꺼져도 반쯤 쓴 파일이 남지 않아요. 광고 · 로그인 · 인터넷 업로드가 없고, 파일은 이 PC와 고른 드라이브 사이에서만 오가요.

이렇게 써요

  1. [+ 새 작업]을 누르고 백업할 폴더(원본)와 넣을 곳(대상)을 골라요. 큰 화살표가 방향을 보여 줘요.
  2. 방식을 골라요: 백업(지운 파일도 남김) · 거울(대상을 원본과 똑같이) · 양쪽 동기화(두 폴더를 서로 맞춤).
  3. [비교 미리보기]로 바뀔 것을 확인하고 [이대로 실행]을 눌러요.
  4. 원하면 [자동 실행]에서 매일 · 매시간 · 컴퓨터 켤 때 · USB 꽂을 때 · 파일이 바뀔 때 백업하게 해요.

할 수 있는 것

🔍 실행 전 미리보기새것 · 바뀐 것 · 지울 것 · 충돌을 종류별로 묶어 보여 줘요. 줄마다 이번에는 빼거나, 충돌이면 어느 쪽을 쓸지 고를 수 있어요.
🕘 예전 버전 되살리기덮어쓰거나 지운 파일은 날짜별 보관함에 남아요. 파일 이름으로 찾아서 원하는 날짜 버전을 원래 자리나 다른 곳에 되살려요. 며칠 · 몇 개까지 남길지 정해요.
🔁 방식 세 가지백업(원본에서 지워도 대상에 남김), 거울(대상을 원본과 똑같이), 양쪽 동기화(노트북 ↔ USB처럼 어느 쪽에서 고쳐도 맞춤, 양쪽 다 고친 파일은 건드리지 않고 알림).
⏰ 예약 실행컴퓨터 켤 때 · 매일 정한 시각 · 매시간 중에 골라요. 윈도우 작업 스케줄러에 내 권한으로 넣어서 관리자 권한이 필요 없고, 컴퓨터가 꺼져 있어 놓친 예약은 켜진 뒤 바로 해요.
💾 USB 꽂으면 자동 백업백업 USB를 드라이브 고유 번호(또는 이름)로 알아봐요. 꽂을 때마다 드라이브 글자(E: · F:)가 바뀌어도 같은 USB를 찾아가요.
👀 실시간 감시원본 폴더에서 파일이 바뀌면 몇 초(기본 10초) 조용해진 뒤 바로 백업해요.
🛡 안전장치원본이 없거나 비었을 때 · 많은 파일이 지워질 때 · 대상이 갑자기 비었을 때 · 원본과 대상을 거꾸로 고른 것 같을 때 · 공간이 모자랄 때 먼저 멈추고 물어봐요. 자동 실행 중이면 실행하지 않고 알려 줘요.
🚚 옮긴 파일 · 폴더 알아보기원본에서 폴더 이름을 바꾸거나 파일을 다른 폴더로 옮기면, 대상에서도 다시 복사하지 않고 옮기기만 해요. 큰 사진 · 동영상 폴더도 순식간이에요.
🧹 빼기 규칙 · 쓰는 중인 파일*.tmp, node_modules 같은 것은 체크 한 번으로 빼요. 다른 프로그램이 열어 둔 파일은 건너뛰고 알려 준 뒤 다음 백업 때 다시 해요. 긴 경로 · 한글 · 특수 문자 이름도 그대로 돼요.

자세한 사양

백업할 수 있는 곳이 PC의 다른 폴더 · 외장 하드 · USB · 네트워크 폴더(\\NAS\…)
빠르기 (파일 10만 개 · 10GB)처음 백업 약 15초 · 고친 뒤 다시 맞추기 약 1.6초 · 바뀐 것 없을 때 비교 약 0.5초 (이 PC 기준. 함께 잰 윈도우 기본 복사 도구 robocopy: 처음 22초 · 다시 맞추기 3.1초)
예전 버전대상 폴더 안 '.cavalier-versions\날짜 시각' — 탐색기로도 바로 보여요
필요한 것Windows 10 · 11 (64비트), 관리자 권한 필요 없음

무료로 시작하기

무료

  • 처음 7일은 모든 기능 그대로
  • 7일 뒤에도 계속 무료: 작업 만들기 · 비교 미리보기 · 예전 버전 되살리기 · 실행 기록 보기는 7일 뒤에도 계속 무료이고 기다림도 없어요.
  • 무료판: [지금 백업]을 누를 때 15초 기다려요. 자동 실행(예약 · USB 꽂으면 · 실시간 감시)은 정식판 기능이에요. 무료판에서 자동 실행 때가 되면 트레이로 알려 드려서 백업이 조용히 멈추지 않아요.

정식 라이선스

  • 기다림 · 제한 없이 모든 기능
  • 기간 제한 없음
  • 올인원 키 하나로 유틸 모두 정식판
이메일로 문의하기
  1. zip 파일을 받아요.
  2. 압축을 풀고 CavalierBackup.exe를 실행해요. 설치 과정은 없어요.
  3. "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 눌러요.

Cavalier Backup 0.1.12026-11-14
  • 고친 것: 원본 안에 열 권한이 없는 폴더가 있으면, '거울' 백업이 그 폴더의 백업을 지운 것으로 보고 보관함으로 옮기던 문제를 고쳤어요. ('양쪽 동기화'에서는 반대쪽 파일까지 지워질 수 있었어요.) 이제 읽지 못한 폴더 안은 건드리지 않고 알려 드려요.
  • 고친 것: 백업하는 드라이브 공간이 꽉 차거나 USB가 빠지면, 남은 파일을 하나하나 다 실패하던 것을 고쳤어요. 이제 바로 멈추고 "공간이 꽉 찼어요" · "드라이브가 빠졌어요"라고 알려 드리고, 아무것도 지우지 않아요. 다시 하면 이어서 해요.
  • 고친 것: 원본 폴더를 열 권한이 없거나 파일을 열 권한이 없을 때 영어 오류가 나오던 것을 쉬운 한국어로 바꿨어요.
  • 고친 것: [지금 백업]이 끝났는데 실패하거나 건너뛴 파일이 있으면, 몇 개가 왜 안 됐는지 결과 창으로 보여 드려요. 파일마다 이유를 보고 복사할 수 있어요.
  • 고친 것: 예상하지 못한 오류가 생겨도 프로그램이 꺼지지 않고 쉬운 말로 알려 드려요. 자세한 내용은 설정 폴더의 errors.log 에 남아요.
  • 확인한 것: 쓰는 중인 파일은 건너뛰고 다음에 다시 해요. 빈 파일 · 잘린 사진 · 이름만 바꾼 파일 · 이모지 이름 · 읽기 전용 · 아주 긴 경로 · 5GB 파일도 잘 돼요. 백업 도중 컴퓨터가 꺼진 것처럼 강제로 끝내도 다시 하면 바이트까지 똑같아요.

자주 묻는 질문

백업한 파일은 어떤 모양으로 저장되나요?

원본과 똑같은 폴더 · 파일 그대로 복사돼요. 특별한 압축 파일이 아니라서 이 프로그램이 없어도 탐색기로 바로 열 수 있어요.

실수로 원본을 지웠는데 백업에서도 지워지나요?

'백업' 방식이면 대상에는 그대로 남아요. '거울' · '양쪽 동기화'여도 지워지는 파일은 먼저 예전 버전 보관함으로 옮겨서, [예전 버전]에서 되살릴 수 있어요.

엑셀처럼 열어 둔 파일은 어떻게 되나요?

건너뛰고 어떤 파일인지 알려 드려요. 나머지는 모두 백업하고, 그 파일은 다음 백업 때 다시 해요. 관리자로 켜면 열린 파일도 복사하는 방법(VSS)을 고를 수 있어요.

백업 중에 컴퓨터가 꺼지면요?

반쯤 쓴 파일이 다 된 파일처럼 남지 않게 만들었어요. 다음에 실행하면 멈춘 곳부터 마저 해요.

설치는 어떻게 하나요?

zip 파일을 받아 원하는 곳에 압축을 풀고 exe 를 실행하면 끝이에요. 지우고 싶으면 폴더를 지우면 돼요. 여러 프로그램을 한 번에 설치 · 업데이트하려면 Cavalier 설치 도우미를 쓰세요.

7일이 지나면 어떻게 되나요?

무료판으로 계속 쓸 수 있어요. 자주 쓰는 기능은 그대로 무료이고, 큰 작업만 잠깐 기다리거나 정식판에서만 돼요.

"Windows의 PC 보호" 창이 떠요.

새로 나온 프로그램이라 나오는 안내예요. [추가 정보] → [실행]을 눌러 주세요.

인터넷에 제 정보를 보내나요?

아니요. 켤 때 홈페이지에서 '사용 중지된 키 목록'만 받아 오고, 이때도 내 정보는 보내지 않아요.
