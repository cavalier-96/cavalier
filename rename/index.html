Cavalier Rename · 파일 이름 한꺼번에 바꾸기

파일 이름 수천 개,
미리 보고 한 번에 바꾸세요

여러 파일과 폴더의 이름을 규칙대로 한꺼번에 바꿔 주는 프로그램이에요. 바뀔 이름을 먼저 보여 주고, 바꾼 뒤에도 언제든 원래 이름으로 되돌릴 수 있어요.

무료로 내려받기
Windows 10 · 11 (64비트)

어떤 프로그램인가요?

여행 사진을 찍은 날짜 순서로 정리하거나, 음악 파일 이름을 '가수 - 제목'으로 맞추거나, 회사 문서 이름 앞에 날짜를 붙일 때 좋아요. 파일을 하나씩 눌러 이름을 고치는 대신, 규칙을 한 번 정하면 1만 개도 1~2초 안에 끝나요.

바꾸기 전에 기록을 먼저 남겨서, 바꾼 뒤에도 · 프로그램을 껐다 켠 뒤에도 · 중간에 꺼졌어도 되돌릴 수 있어요. 이름이 겹치면 덮어쓰지 않고 자동으로 "(2)"를 붙여 알려 줘요. 광고 · 로그인 · 인터넷 업로드가 없고, 모든 일은 내 PC 안에서만 해요.

이렇게 써요

  1. 파일이나 폴더를 창에 끌어다 놓아요. 탐색기에서 파일을 골라 오른쪽 클릭 → 'Cavalier Rename 으로 이름 바꾸기'를 눌러도 돼요.
  2. 왼쪽에서 규칙을 골라 채워요. '+ 규칙 추가'로 여러 규칙을 쌓으면 위에서부터 차례로 적용돼요.
  3. 오른쪽 표에서 바뀔 이름을 미리 봐요. 바뀌는 글자는 색으로 보이고, 바꾸고 싶지 않은 줄은 체크를 끄면 돼요.
  4. '이름 바꾸기'를 누르면 끝이에요. 마음에 안 들면 '되돌리기'를 눌러요.

할 수 있는 것

👀 바뀔 이름 미리보기규칙을 고치는 순간 바뀔 이름이 표에 바로 보여요. 미리보기는 파일을 전혀 건드리지 않고, 바뀔 이름을 두 번 눌러 직접 고칠 수도 있어요.
↩️ 바꾼 뒤에도 되돌리기바꾸기 전에 기록을 먼저 남겨요. '기록'에서 최근 300번의 이름 바꾸기를 골라 되돌리거나 다시 바꿀 수 있고, 프로그램을 껐다 켜도 그대로예요.
🧩 규칙 11가지를 쌓아서글자 바꾸기 · 앞뒤에 붙이기 · 지우기 · 번호 · 대소문자 · 확장자 · 글자 정리 · 날짜 · 음악 태그 · 꼬리표로 새 이름 짓기 · 목록대로 바꾸기를 원하는 만큼 쌓아요. 켜고 끄기 · 순서 바꾸기도 돼요.
📷 사진 찍은 날짜로사진 속에 적힌 찍은 날짜를 읽어서 '2026-08-14_001.jpg'처럼 바꿔요. 휴대폰 사진(JPEG · HEIC), 카메라 RAW 10종, 동영상(MP4 · MOV)까지 읽어요.
🎵 음악 태그로음악 파일 안의 가수 · 제목 · 앨범 · 트랙 번호를 읽어서 '01. 아이유 - 밤편지.mp3'처럼 바꿔요. MP3 · FLAC · M4A · OGG · OPUS · WAV를 읽어요.
🛡️ 겹침 · 실수 막기이름이 겹치면 덮어쓰지 않고 자동으로 "(2)"를 붙여 주황색으로 알려요. 윈도우에서 못 쓰는 글자나 너무 긴 이름도 미리 잡아서 고쳐요.
🔤 찾아 바꾸기 · 정규식글자를 찾아 바꾸는 것은 물론, 고급 사용자는 정규식(글자 모양 규칙)으로 복잡한 이름도 한 번에 바꿀 수 있어요. 규칙이 틀리면 어디가 틀렸는지 바로 알려 줘요.
🧹 지저분한 이름 정리띄어쓰기 정리, 맥에서 온 깨진 한글 이름 고치기, 이모지 지우기, 내용을 보고 진짜 확장자로 고치기(사진인데 .txt로 된 파일 등)를 해요.
💾 규칙 저장 · 탐색기 메뉴자주 쓰는 규칙은 저장해 두고 다시 불러와요. 탐색기 오른쪽 클릭 메뉴는 이 사용자에게만 등록돼서 관리자 권한이 필요 없어요.

자주 묻는 질문

이름을 잘못 바꿨어요. 되돌릴 수 있나요?

네. '되돌리기'를 누르거나 '기록'에서 예전 이름 바꾸기를 골라 되돌리면 돼요. 프로그램을 껐다 켠 뒤에도, 중간에 꺼졌어도 되돌릴 수 있어요. 되돌리기는 무료판에서도 기다림 없이 돼요.

파일 내용이 바뀌거나 사진 화질이 떨어지지는 않나요?

아니요. 이름만 바꾸고 파일 내용은 절대 건드리지 않아요. 사진 날짜도 읽기만 해요.

바꾼 이름이 다른 파일과 겹치면 어떻게 되나요?

덮어쓰지 않아요. 자동으로 "(2)"를 붙이거나, 설정에서 그 파일은 빼고 알려 주도록 고를 수 있어요. 미리보기에서 주황색으로 먼저 보여 줘요.

사진에 찍은 날짜가 없으면요?

찍은 날짜가 없는 사진(메신저로 받은 사진 등)은 파일을 고친 날을 대신 써요. 이 기능은 끌 수 있어요.

다른 프로그램이 쓰고 있는 파일은요?

그 파일만 건너뛰고 "다른 프로그램이 쓰고 있어요"라고 알려 줘요. 나머지 파일은 그대로 바뀌어요.

설치는 어떻게 하나요?

zip 파일을 받아 원하는 곳에 압축을 풀고 exe 를 실행하면 끝이에요. 지우고 싶으면 폴더를 지우면 돼요. 여러 프로그램을 한 번에 설치 · 업데이트하려면 Cavalier 설치 도우미를 쓰세요.

7일이 지나면 어떻게 되나요?

무료판으로 계속 쓸 수 있어요. 자주 쓰는 기능은 그대로 무료이고, 큰 작업만 잠깐 기다리거나 정식판에서만 돼요.

"Windows의 PC 보호" 창이 떠요.

새로 나온 프로그램이라 나오는 안내예요. [추가 정보] → [실행]을 눌러 주세요.

인터넷에 제 정보를 보내나요?

아니요. 켤 때 홈페이지에서 '사용 중지된 키 목록'만 받아 오고, 이때도 내 정보는 보내지 않아요.
