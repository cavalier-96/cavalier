Cavalier Find · 파일 이름 즉시 찾기 · 빠른 실행기

PC 안의 파일을
치는 순간 찾아요

파일 이름 일부만 치면 PC 전체에서 바로 찾아 주는 프로그램이에요. 프로그램 실행 · 계산 · 윈도우 설정 열기도 단축키 하나로 해요.

무료로 내려받기
Windows 10 · 11 (64비트)

어떤 프로그램인가요?

"그 파일 어디 뒀더라?" 할 때 좋아요. 탐색기 검색처럼 기다릴 필요 없이, 글자를 칠 때마다 결과가 바로 바뀌어요. 파일 수십만 개 중에서도 보통 0.01초 안에 찾고, 방금 만든 파일도 곧바로 나타나요.

광고 · 로그인 · 인터넷 업로드가 없어요. 파일 이름 목록은 내 PC에만 저장돼요. 관리자 권한 없이 그대로 쓸 수 있고, 한글 초성(ㅂㄱㅅ → 보고서)이나 맥에서 만든 한글 이름처럼 한국어 사용자에게 필요한 찾기도 돼요.

이렇게 써요

  1. 압축을 풀고 CavalierFind.exe 를 실행해요. 처음 한 번 PC의 파일 이름을 모아요 (파일 약 95만 개에 몇 초).
  2. 위의 큰 칸에 찾을 이름 일부를 쳐요. 예: 제주 mp4 · *.pdf · 보고서 dm:이번주
  3. 결과에서 Enter 로 열고, Ctrl+Enter 로 들어 있는 폴더를 열어요. 위쪽 단추로 사진 · 동영상 · 문서만 골라 볼 수도 있어요.
  4. 다른 프로그램을 쓰다가도 단축키(기본 Ctrl+Alt+Space)를 누르면 작은 찾기 창이 떠요.

할 수 있는 것

⚡ 치는 순간 찾기글자를 칠 때마다 결과가 바로 바뀌어요. 띄어쓰기는 '그리고', | 는 '또는', ! 는 '빼기'예요. 수십만 개 결과도 끊김 없이 넘겨 봐요.
🔄 실시간 반영새로 만들거나 지우거나 이름을 바꾼 파일이 바로 찾기 결과에 반영돼요. 껐다 켜도 꺼져 있던 동안 바뀐 것을 따라잡아요.
🗂️ 종류 · 크기 · 날짜로 거르기사진 · 동영상 · 문서 · 음악 · 압축 단추에 개수가 보여요. [크기·날짜 조건] 단추로 '10MB 넘는 이번 주 파일' 같은 조건을 쉽게 붙여요.
🔤 한국어에 맞춘 찾기초성만으로 찾기(ㅂㄱㅅ → 보고서), 맥에서 만든 풀어쓴 한글 이름, 전각 글자, 'dm:오늘 · 이번주 · 지난달' 같은 한국어 날짜 낱말을 알아들어요.
🖼️ 미리보기와 파일 정보고른 파일을 오른쪽에서 바로 봐요. 사진 · 동영상 · PDF 미리보기와 해상도 · 재생 시간 · 가수 같은 정보가 보이고, 'width:>1920 · length:>10분'처럼 이런 정보로도 찾아요.
📄 내용까지 찾기파일 안의 글로도 찾아요. 한글(hwp · hwpx) · Word · Excel · PowerPoint · PDF · 글 파일을 읽어요. 자주 찾는 폴더는 '내용 색인'을 켜면 바로 찾아요.
🚀 빠른 실행기단축키로 뜨는 작은 창에서 프로그램 이름, 계산(12*30 → 360), 윈도우 설정(디스플레이 · 소리 · 블루투스 …)을 파일과 함께 찾아 바로 실행해요.
🧹 중복 파일 찾기내용이 똑같은 파일을 묶어서 보여 주고, 얼마나 공간을 줄일 수 있는지 알려 줘요. 지울 때는 휴지통으로만 옮겨서 되살릴 수 있어요.
⭐ 북마크 · 기록 · 목록 내보내기자주 쓰는 찾기를 북마크로 저장하고, 찾은 말 기록과 파일 변경 기록을 볼 수 있어요. 결과를 CSV · TXT · 파일 목록(EFU)으로 내보내고, 명령줄(cfind.exe)로도 찾아요.

자세한 사양

찾는 곳PC의 모든 드라이브 (NTFS는 실시간 반영), USB · 외장 드라이브 (꽂으면 자동), 네트워크 공유 폴더
빠르기보통 검색 0.002초 안팎, 정규식 · 와일드카드도 0.01초 안팎 (파일 약 95만 개, 이 PC 기준)
처음 준비관리자 권한 없이 파일 약 95만 개를 1~4초에 모아요. 다음부터는 0.2초에 불러와요
새 파일 반영만든 뒤 약 0.0003초 (이 PC 기준)
필요한 것Windows 10 · 11 (64비트). 메모리는 파일 95만 개 기준 약 280MB를 써요
크기내려받기 약 58MB (압축을 풀면 약 148MB)

  • 무료판: 중복 파일 찾기 · 내용 색인 만들기 · 목록 내보내기를 할 때만 15초 기다려요

정식 라이선스

  • 기다림 · 제한 없이 모든 기능
  • 기간 제한 없음
  • 올인원 키 하나로 유틸 모두 정식판
이메일로 문의하기
  1. zip 파일을 받아요.
  2. 압축을 풀고 CavalierFind.exe를 실행해요. 설치 과정은 없어요.
  3. "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 눌러요.

모든 업데이트 기록 보기

자주 묻는 질문

관리자 권한이 필요한가요?

아니요. 그대로 쓸 수 있어요. [설정 → 색인 → 관리자 모드 켜기]를 누르면 관리자 허락을 한 번 받아 작은 도우미를 설치해요. 그러면 처음 준비가 더 빠르고, 관리자만 열 수 있는 폴더의 이름까지 찾아요. 언제든 [관리자 모드 끄기]로 지울 수 있어요.

내 파일 이름이 어딘가로 보내지나요?

아니요. 파일 이름 목록은 내 PC(%LOCALAPPDATA%\CavalierFind)에만 저장되고, 인터넷으로 보내지 않아요. 파일을 고치거나 지우지도 않아요.

찾을 때 쓸 수 있는 조건을 다 알고 싶어요

[더 보기 → 찾는 법]에 모두 있어요. 예: ext:jpg;png · size:>100mb · dm:이번주 · parent:D:\사진 · content:"계약" · regex:^IMG_\d+

단축키가 다른 프로그램과 겹치면요?

다른 프로그램이 이미 쓰는 키는 빼앗지 않고 다음 후보 키로 바꿔서 알려 줘요. [설정 → 실행기]에서 원하는 키로 바꿀 수 있어요.

설치는 어떻게 하나요?

zip 파일을 받아 원하는 곳에 압축을 풀고 exe 를 실행하면 끝이에요. 지우고 싶으면 폴더를 지우면 돼요. 여러 프로그램을 한 번에 설치 · 업데이트하려면 Cavalier 설치 도우미를 쓰세요.

7일이 지나면 어떻게 되나요?

무료판으로 계속 쓸 수 있어요. 자주 쓰는 기능은 그대로 무료이고, 큰 작업만 잠깐 기다리거나 정식판에서만 돼요.

"Windows의 PC 보호" 창이 떠요.

새로 나온 프로그램이라 나오는 안내예요. [추가 정보] → [실행]을 눌러 주세요.

인터넷에 제 정보를 보내나요?

아니요. 켤 때 홈페이지에서 '사용 중지된 키 목록'만 받아 오고, 이때도 내 정보는 보내지 않아요.
